# qA_aim　装甲板识别与运动预测（自瞄方向）

## 本目录应包含

| 文件 / 目录 | 说明 |
|---|---|
| `detect.py` | 装甲板识别 + PnP 位姿解算，输出 `detections_*.csv` 与可视化视频 |
| `track.py` / `predict.py` | 卡尔曼滤波与 0.25 s 运动预测，输出 `pred_*.csv` |
| `tune_threshold.py` | 阈值调节工具（滑动条实时调参） |
| `spin.py` | 小陀螺车体中心与角速度估计（发挥部分） |
| `figures/` | 全部可视化材料 |
| `detections_*.csv` | 识别与位姿结果 |
| `pred_*.csv` | 预测 / 估计结果 |

## 数据格式（严格按考核要求）

**识别与位姿结果** `detections_<视频名>.csv`

```
frame,lt_x,lt_y,lb_x,lb_y,rb_x,rb_y,rt_x,rt_y,x,y,z,yaw
```

- 每块装甲板一行，同帧可多行；未识别的帧不写
- 关键点顺序：左灯条上端 → 左灯条下端 → 右灯条下端 → 右灯条上端
- `装甲板_蓝.mp4` **位姿列留空**

**平移预测结果** `pred_远距离平移.csv`

```
t,x,y,z
```
`x, y, z` 为对 `t + 0.25 s` 时刻装甲板位置的预测。

**小陀螺估计结果** `pred_<视频名>.csv`

```
t,cx,cy,cz,omega
```
`cx, cy, cz` 为当前车体中心，`omega` 为旋转角速度（rad/s）。

## figures/ 清单

1. 每段视频的识别结果视频（标出四边形与关键点顺序）
2. `远距离平移`：装甲板位置随时间曲线、俯视轨迹（x–z 平面）
3. `远距离平移`：观测值 / 滤波值 / 预测值对比曲线 + "预测值 vs 0.25 s 后观测值"对比曲线与误差统计
4. （发挥）小陀螺：装甲板观测位置与车体中心估计值对比曲线、角速度估计曲线
5. （发挥）Q、R 参数对比图

## 关键参数

- 相机内参：`data/armor/camera_info.json`（8 mm 镜头，1440×1080）
- 装甲板：灯条长 55 mm，两灯条中心距 135 mm
- 前 3 段视频 150 fps，第 n 帧（从 0 起）时间戳 = n / 150 s
- 坐标系：相机坐标系，x 右 / y 下 / z 前，单位 m
- 预测提前量：0.25 s

## 自检方法（本题不给真值）

- [ ] ① 0.25 s 前的预测值应与当前帧实际观测值一致
- [ ] ② 小陀螺视频中车体中心在空间中不动
- [ ] ③ 平移视频中测试台沿直线导轨运动
