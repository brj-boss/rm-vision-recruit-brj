# q2_calib　相机标定与单目测距

## 方案选择

题二原文允许两种标定板载体：

> 制作棋盘格标定板（打印后贴于硬质平板，**或在另一显示屏上全屏显示**），并实际测量方格边长。

本项目采用 **另一显示屏全屏显示** 方案（手机拍摄）。两条路的差别与风险见 [`CAPTURE_GUIDE.md`](CAPTURE_GUIDE.md)，
核心一点：屏幕方案的方格边长不是标称值，**必须用直尺实测**。

## 文件清单

| 文件 / 目录 | 说明 |
|---|---|
| `gen_chessboard.py` | 生成棋盘格。`--a4` 出打印版（毫米制，300 DPI），`--screen` 出满屏版（像素制，按显示器原生分辨率） |
| `capture_calib.py` | **笔记本摄像头**采集，20 个姿态逐个引导 + 实时角点校验，检不出不允许保存 |
| `check_images.py` | **手机照片**入库前处理：EXIF 转正 → 竖拍自动旋转 90° → 缩放 → 角点批量检查，输出可用副本与检查拼图 |
| `calibrate.py` | 角点提取 → `cornerSubPix` 亚像素精化 → `calibrateCamera` → 逐张重投影误差 |
| `_selftest.py` | 合成数据自检：用已知真值的 `(K, dist)` 渲染 → 反解 → 比对，验证整条链路 |
| `CAPTURE_GUIDE.md` | 拍摄指南（屏幕方案）：屏幕/手机设置、20 张姿态表、卷尺要求、传图方式 |
| `board/` | 棋盘格文件：`chessboard_9x6_18mm_a4.png`（打印版）、`chessboard_9x6_screen_1920x1200.png`（满屏版） |
| `phone_raw/` | 手机原图（**不入库**，单张 3~5 MB） |
| `calib_images/` | 转正缩小后的标定图副本（入库），`calibrate.py` 默认读这里 |
| `measure_images/` | A4 纸测距照片（画面里要有卷尺） |
| `q2_figs/` | 结果图：角点检测拼图、去畸变对比、误差曲线、角度对比 |
| `results/` | `camera_calib.npz` / `.json`、测距数据表 |

## 关键参数

| 参数 | 值 | 说明 |
|---|---|---|
| 棋盘内角点 | 9 × 6 | 即 10 × 7 个方格 |
| 方格边长 | **待实测** | 屏幕上用直尺量 10 格总长 ÷ 10，传给 `--square` |
| A4 纸尺寸 | 210 × 297 mm | 测距目标 |
| 测距范围 | 0.5 ~ 3.0 m | 不少于 5 组 |

## 流程

```powershell
cd D:\rm-vision-recruit-brj

# 1) 生成满屏棋盘格（按当前显示器分辨率）
.venv\Scripts\python.exe q2_calib\gen_chessboard.py --screen

# 2) 手机拍照 → 传进 q2_calib\phone_raw\

# 3) 批量检查 + 转正 + 缩放，看 q2_figs\corner_check.png 剔废图
.venv\Scripts\python.exe q2_calib\check_images.py

# 4) 标定，--square 填实测值
.venv\Scripts\python.exe q2_calib\calibrate.py --square 30.5
```

## 自检结论（合成数据，已验证链路正确）

用已知真值渲染 20 张合成棋盘格，再走同一套流程反解：

| 参数 | 真值 | 反解 | 偏差 |
|---|---|---|---|
| fx | 905 px | 906.8 px | 0.20% |
| fy | 902 px | 903.5 px | 0.16% |
| k1 | −0.152 | −0.1527 | ~0.5% |
| 重投影 RMS | — | 0.140 px | — |

自检过程中暴露的两个问题，本身是可写进报告的结论：

1. **顶点数**：9×6 内角点对应 10×7 个方格，顶点应为 11×8。按内角点数画会少一行一列，检测器直接 0 张检出。
2. **全正对拍摄导致标定退化**：20 张全正对时，`RMS = 0.138 px`（拟合极好）但 `fx = 4982`（真值 905，差 5 倍）。
   原因是焦距与拍摄距离可互相补偿 —— **fx 放大 5 倍、距离缩小 5 倍，重投影完全一致**，方程解不唯一。
   这直接解释了「为什么标定图必须有倾斜姿态」，也是发挥部分对比实验②的理论依据。
