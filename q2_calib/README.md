# q2_calib　相机标定与单目测距

## 本目录应包含

| 文件 / 目录 | 说明 |
|---|---|
| `calibrate.py` | 标定脚本：读标定图 → `cv2.calibrateCamera` → 输出内参、畸变、重投影误差 |
| `undistort.py` | 去畸变，输出去畸变前后对比图 |
| `measure.py` | `cv2.solvePnP` 单目测距 |
| `board/` | 棋盘格文件（打印用的 PDF/PNG，或截屏备用） |
| `calib_images/` | 实际采集的 15～25 张标定图 |
| `measure_images/` | 测距用的 A4 纸照片（**画面里要有卷尺作为实测依据**） |
| `q2_figs/` | 结果图：角点检测图、去畸变对比图、误差曲线、角度对比图 |
| `results/` | 标定结果（`camera_matrix.npz` 或 `.json`）、测距数据表 |

## 关键参数

- 棋盘格方格实测边长：**待填** mm（务必用尺子量，不要用标称值）
- 棋盘格内角点数：**待填**（如 9×6）
- A4 纸尺寸：210 mm × 297 mm
- 测距范围：约 0.5 m ～ 3 m，不少于 5 组

- 本题数据必须**本人采集**，不能用网图。
- 发挥部分的对比实验：
  - ① 只用 5 张标定图
  - ② 标定图全部正对拍摄
  - ③ 方格边长故意输错（实际 25 mm 输成 20 mm）
